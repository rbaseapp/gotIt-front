# Home dashboard: learning choices and useful progress

The home page answers two questions in order: **What can I do now?** and
**How am I doing?** The two primary choices are word practice and a private
lesson with the AI teacher. Each card names the activity and describes what
the destination offers. A user without saved words goes to the vocabulary
library to add words before starting practice.

An existing course or unfinished lesson exercise appears as a contextual
shortcut. It is labelled as part of private lessons so it cannot be mistaken
for independent word practice. With no course or unfinished exercise, the
shortcut is absent.

The default progress view shows only words due now, mastered words, and the
daily goal. These numbers help the user decide whether to review words today
and see immediate progress. Words that need strengthening appear only when
there are any. Library breakdown, skill scores, weekly history, XP, streak,
and recent attempts remain available under **More word progress details** for
users who want to inspect them. Detailed gamification rules and time zone
explanations do not belong in the first screen.

The two activity cards remain visible when dashboard data fails to load, so
the user can still enter a lesson or practice. The dashboard error retains a
retry action. On narrow screens the cards and progress items stack in the
same reading order. Each destination is identified by text as well as its
icon and color.
